# LAN SHARE v2 — Advanced UI

نسخه پیشرفته‌تر با طراحی الهام‌گرفته از نمونه تصویری ارسالی: تیره، مینیمال، سینمایی و با کارت شیشه‌ای.

## امکانات
- انتقال دوطرفه بین موبایل و کامپیوتر
- فقط یک Wi-Fi مشترک؛ اینترنت لازم نیست
- drag & drop
- نوار پیشرفت واقعی آپلود
- دانلود و حذف فایل
- نمایش تعداد و حجم فایل‌ها
- رابط responsive برای موبایل
- پشتیبانی فایل تا 10GB در هر آپلود (وابسته به فضای دیسک و سیستم عامل)

## اجرا
Python 3:
```bash
python app.py
```
سپس آدرس `http://IP:8000` را که در ترمینال چاپ می‌شود در موبایل باز کنید.

### اگر روی موبایل باز نشد
Firewall سیستم عامل ممکن است Python یا پورت 8000 را مسدود کرده باشد. اجازه دسترسی روی شبکه Private/Home را فعال کنید.

## درباره «در هر جا»
این نسخه در هر جایی که موبایل و کامپیوتر روی یک شبکه محلی مشترک باشند کار می‌کند، حتی اگر اینترنت آن شبکه قطع باشد.
برای انتقال از فاصله دور/شبکه‌های متفاوت، باید نسخه اینترنتی با signaling و WebRTC یا سرور relay اضافه شود؛ آن حالت با نسخه LAN فرق دارد.
